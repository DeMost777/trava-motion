# Вставка в Webflow — пошаговая инструкция

**Для кого:** тот, кто работает в Webflow Designer. **Что получится:** иллюстрация Queue Manager анимируется на сайте.
Сначала публикуем только на **staging** (`*.webflow.io`), на боевой сайт — после проверки.
Решение о способе доставки — [ADR 0017](../../docs/decisions/0017-webflow-delivery.md).

## Файлы в этой папке
| Файл | Куда |
|---|---|
| `queue-manager.svg` | загрузить в **Assets** Webflow |
| `webflow-custom-code.html` | **скопировать целиком** в Custom code страницы (GSAP + код, 16 КБ) |
| `trava-motion.js` | тот же код отдельным файлом (для разработки; в Webflow не нужен) |

Файлы собирает `node tools/build-webflow.mjs` — руками не редактировать.

## Шаги
1. **Загрузить SVG.** Designer → панель **Assets** → **Upload** → `queue-manager.svg`.
2. **Заменить картинку в карточке Queue Manager.** Выделить изображение иллюстрации в карточке (у элемента класс
   `solution-visual-image`) → в настройках изображения **Replace image** → выбрать загруженный `queue-manager.svg`.
   Alt text — пустой (иллюстрация декоративная, смысл передаёт текст карточки).
   ⚠ Это должен быть элемент **Image** (`<img>`). Если иллюстрация стоит фоном (background-image) — остановитесь и напишите мне.
3. **Добавить атрибут.** У того же изображения: **Element settings** (иконка шестерёнки) → **Custom attributes** → **+**:
   - Name: `data-trava-animation`
   - Value: `queue-manager`
4. **Подключить код.** Открыть `webflow-custom-code.html` в любом текстовом редакторе (или в браузере через
   «Просмотр кода»), выделить **всё** и скопировать. **Pages** → настройки главной страницы → **Custom code** →
   поле **Before `</body>` tag** → вставить. Ничего не менять внутри.
5. **Опубликовать на staging** (Publish → только `*.webflow.io`).

## Проверка на staging
1. Открыть страницу, прокрутить до карточки Queue Manager — импульсы бегут к центру, через ~3.4 с крутится gear.
2. Прокрутить дальше и вернуться — анимация начинается заново, без рывков.
3. Перейти на карточку кликом в сайдбаре — анимация тоже запускается.
4. Компьютер, планшет, телефон.
5. Включить «уменьшить движение» в системе (macOS: Универсальный доступ → Дисплей; iOS: Универсальный доступ →
   Движение) — иллюстрация статичная, как в макете.
6. **Если анимации нет:** открыть консоль браузера (F12 → Console) и прислать строки с `[trava-motion]`.
   Самая вероятная причина — браузер не дал скрипту прочитать SVG с сервера ассетов Webflow (CORS); тогда
   иллюстрация просто остаётся статичной, сайт не ломается.

## Если на сайте две картинки (десктоп и планшет/телефон)
Как в блоке «Solutions»: у **каждой** картинки иллюстрации — свой Image с тем же ассетом и атрибутом `data-trava-animation`.
После замены ассета Webflow стирает alt — впишите его снова (иначе иллюстрация для экранных дикторов «пропадёт»).
Размеры задают классы сайта; код ширину не меняет. Подробности и проверка — [ADR 0018](../../docs/decisions/0018-queue-manager-ready-for-production.md), `qa/site-solutions.mjs`.

## Откат
Удалить код из шага 4 (или атрибут из шага 3) и опубликовать — останется обычная статичная картинка.
