# Trava Motion

Среда для производства анимаций иллюстраций сайта Trava: Figma SVG + описание движения →
GSAP-анимация → preview → QA → Webflow. Концепция: `docs/concept.md`. План: `BACKLOG.md`.

## Рабочий процесс
- IMPORTANT: делай только текущую задачу из `BACKLOG.md`. Не начинай следующую задачу или фазу без явного утверждения.
- Цикл задачи: исследование → план с проверкой → ✋ утверждение → реализация → проверка → коммит.
  Подробно: `docs/ai-environment.md`, раздел 5.
- Задача с ✋ закрывается только после ответа «утверждаю». Решение записывается в `docs/decisions/` по шаблону `0000-template.md`.
- Не выбирай за команду принципы движения, токены, стек и форматы. Предложи 2–3 варианта с рекомендацией.
  Нерешённый вопрос добавь в `docs/open-questions.md`.
- Работа считается сделанной, когда пройдена проверка из колонки «Готово, когда».
  Покажи доказательство (вывод команды, скриншот). Если проверить нельзя, скажи об этом прямо.
- После задачи обнови статус в `BACKLOG.md`.

## Неизменные принципы
- Figma — визуальный source of truth. Анимируем существующий дизайн, не перерисовываем и не меняем стиль.
- Анимация — enhancement: без неё (reduced motion, ошибка) иллюстрация полностью читаема.
- Знания живут в репозитории (docs, `.claude/`), а не в истории чатов.
