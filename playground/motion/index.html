В системе включено «уменьшить движение». Стенд всё равно показывает анимации: он нужен, чтобы их выбирать.

1. Easing — характер ускорения

Выберите роль, посмотрите кривые и нажмите на подходящую. Длительность фиксирована (0.6 с, отрисовка линии 1.0 с).

2. Длительности

Одно и то же появление (fade + сдвиг 12 px, кривая power2.out) с разной длительностью. Выберите роль и назначьте ей длительность.

3. Появление — насколько заметно объект «въезжает»

Fade + сдвиг снизу или fade + масштаб. Длительность 0.35 с, кривая power2.out. Выберите по одному варианту в каждой строке.

4. Stagger — задержка между элементами группы

8 узлов появляются по очереди (масштаб от 0.9 + fade, 0.35 с). Выберите роль и назначьте ей задержку.

5. Темп Queue Manager

Упрощённая схема по координатам фрейма Figma (480×459), не настоящий SVG. Цикл по сценарию: волна импульсов к центру по эстафете → поворот + zoom gear без отскока → импульсы возвращаются на места → пауза → снова.

6. Запуск при скролле

Прокрутите окно ниже. Каждый блок запускается, когда видна указанная часть. Нажмите на блок, чей момент запуска нравится, и выберите задержку старта.
