# preview/

`queue-manager.html` — предпросмотр как на сайте (`<img>` + атрибут + GSAP с CDN + `exports/webflow/trava-motion.js`).
Открывать через локальный сервер из корня репозитория: `python3 -m http.server` → `http://localhost:8000/preview/queue-manager.html`
(из файла `file://` браузер не даст скрипту прочитать SVG).

`queue-manager.mp4` — 14 с анимации на настоящем SVG, кадр за кадром.

`quality-control.html` — стенд Quality Control (`?view=final|card`); `quality-control-site.html` — как на сайте (`<img>` + атрибут + собранный `exports/webflow/trava-motion.js`); видео: `quality-control-final.mp4` (вся иллюстрация, 14 с), `quality-control-card.mp4` (карточка крупно, 8 с).
