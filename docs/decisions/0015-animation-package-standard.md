# 0015. Стандарт пакета анимации

- **Статус:** утверждено
- **Дата:** 2026-10-07
- **Кто утвердил:** команда Trava (в чате)
- **Задача бэклога:** 2.5

## Контекст
После 2.1–2.4 у Queue Manager накопились бриф, сценарий, сырой экспорт, эталон и подготовленный SVG.
Нужно единое устройство папки для всех 8 иллюстраций и место для ожидаемых слоёв (в 2.4 они передавались
в командной строке).

## Варианты
См. [docs/plans/2.5-package-standard.md](../plans/2.5-package-standard.md): раскладка (плоско / по шагам /
рукописное отдельно), паспорт (`figma.json` / spec / storyboard), хранить ли `illustration.svg` в git.

## Решение
1. **Раскладка А:** плоская папка `animations/<name>/`, сырьё из Figma — в `source/`. Состав — `animations/README.md`.
2. **Паспорт А:** `figma.json` (EN): узел Figma, `roles`, файлы экспорта и эталона с SHA-256.
3. **`illustration.svg` хранится в git** и генерируется только инструментом.

## Последствия
- `tools/prepare-svg.mjs animations/<name>` читает `figma.json`; останавливается, если хэши не совпали.
- `qa/check-package.mjs` проверяет состав, хэши и актуальность `illustration.svg`.
- В фазе 3 роли в `motion.yaml` проверяются по `figma.json`.
