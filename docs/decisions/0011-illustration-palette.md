# 0011. Палитра иллюстраций: коллекция «Illustration» в Figma + DTCG

- **Статус:** утверждено
- **Дата:** 2026-10-05
- **Кто утвердил:** команда Trava
- **Задачи бэклога:** 1.8, 1.9 (частично)

## Контекст
Аудит 1.7: цвета иллюстраций почти не привязаны к переменным и не совпадают с палитрой сайта.

## Решение
- **Вариант A:** в Figma создана коллекция переменных **Illustration** (один режим `Value`) с точными текущими
  значениями цветов. Слои рабочей копии Queue Manager (`732:12579`) привязаны к ней — вид не изменился.
- **Формат токенов — W3C DTCG** (подтверждено командой). Файлы: `tokens/motion.tokens.json`,
  `tokens/illustration.tokens.json`.
- **Source of truth для цветов — Figma.** Файлы в `tokens/` выгружаются из Figma и не правятся руками.
- Именование переменных: `<группа>/<роль>` (impulse, accent, card, glow, avatar, shadow), scopes заданы
  (заливки/обводки или цвета эффектов), code syntax WEB: `var(--illustration-<группа>-<роль>)`.
- Оригиналы в карточках (`418:30757`) и главный компонент `Icon: user` (из библиотеки) не менялись;
  цвета аватаров привязаны как переопределения в экземплярах рабочей копии.

## Проверка
Все 301 цвет во фрейме `732:12579` привязаны к переменным, расхождений значений 0, скриншот совпадает.

## Последствия
- Fare Optimizer добавит в коллекцию свои цвета, когда для него будет рабочая копия (фаза 11).
- QA 9.4 сверяет цвета SVG с `tokens/illustration.tokens.json` (+ два цвета сайта).
