# 0007. Исключение для смыслового цикла

- **Статус:** утверждено
- **Дата:** 2026-10-02
- **Кто утвердил:** команда Trava
- **Задача бэклога:** 1.10 (сценарий Queue Manager)
- **Дополняет:** [ADR 0006](0006-motion-principles.md), принцип §6

## Контекст
Принцип §6 требует полной статики после анимации. Бриф Queue Manager требует цикличных
импульсов: смысл иллюстрации — механизм, который работает постоянно.

## Решение
Цикл разрешён как исключение, если он и есть смысл иллюстрации. Условия: утверждается в сценарии
конкретной иллюстрации; ритм «действие → пауза», в паузе кадр = макет; работает только пока
карточка активна и видна; при reduced motion — статика. Подробно: `motion/principles.md` §6.

## Последствия
- Queue Manager: бесконечный цикл волн импульсов и реакции gear.
- Runtime должен уметь ставить цикл на паузу вне экрана и при смене карточки (фаза 6).
- QA проверяет кадр в паузе цикла на совпадение с макетом (фаза 9).
