# 0039. Fare Optimizer: сценарий

- **Статус:** утверждено (темп — по Figma)
- **Дата:** 2026-10-15
- **Кто утвердил:** команда Trava (в чате: «В ней уже есть анимация, и механика должна оставаться такой же», затем «Согласен, применяй свои рекомендации»)
- **Задача бэклога:** Fare Optimizer (иллюстрация 8 по [ADR 0012](0012-illustration-audit.md); закрывает фазу 11 «POC 2»)

## Решение (вопросы плана `docs/plans/fare-optimizer-start.md`, всё по рекомендации)
1. **Движение — из Figma без изменений.** Цикл 4 с: 5 точек и 5 бейджей по очереди (старты 0, 0.8, 1.6, 2.4, 3.2 с, по 0.4 с), панель уведомлений (0.8–1.3 с, пружина) и заголовок (проявление), три строки «Saved 80/120/160€» (старты 1.2, 1.9, 2.7 с, пружина с отскоком), колокольчик «звонит» трижды (0.9–1.5, 1.6–2.2, 2.3–2.9 с). График и оси не движутся (как в Figma). Значения и кривые — из `get_motion_context` (см. план).
2. **Конец цикла (вариант А):** как в Figma, срез и цикл с нуля; анимация **стартует с готового вида** (первый кадр = макет, принцип §3). Бесконечный цикл по [ADR 0007](0007-meaningful-loop-exception.md).
3. **Кривые — из Figma, а не токены `motion.ease.*`:** безье `0.7, −0.4, 0.4, 1.4` (точки), `0.5, 0, 0.5, 1` (прозрачность и масштаб бейджей), `0, 0, 0, 1` (сдвиг бейджей) и пружины Figma (формулы из `get_motion_context`). Так движение совпадает с прототипом. Исключение действует только для Fare Optimizer.
4. **Фона с лучами нет** (в макете их нет).
5. **Строки «Saved»** с эффектом Glass в Figma: смотрю экспорт на фоне сайта; если вид расходится, предлагаю варианты команде.
6. **Слои в Figma** (только имена, 2026-10-15): 5 точек → `m-point`; 5 бейджей → `m-badge`; панель → `m-panel`; заголовок → `m-title`; колокольчик → `m-bell`; 3 строки Saved → `m-saving`.

## Что дальше
Команда экспортирует SVG узла `761:9491` («Include id attribute»); далее по `docs/pipeline.md`.

## Реализация (2026-10-15)
- **Экспорт:** команда выгрузила экземпляр «Optimization» (`761:9492`, 480×377), а не всю рамку 480×480 (экземпляр лежит в ней на y=52, остальное пусто). Пакет и эталон — по экземпляру.
- **Цвета** (вариант Б по прецеденту): `#034152` → `#013746`; `#33CAAF` → `#2ABDA3`; серые концы градиентов `#979797`, `#999999` (прозрачность 0, не видны) → `#CBD2D1`. **Красный `#F43D3D`** (участки графика, где цена растёт) токена не имел: по выбору команды (вариант А) добавлен токен `illustration.price.rise` в `tokens/illustration.tokens.json`, вид как в Figma.
- **Техническая правка экспорта:** маска линии под заголовком панели перенесена в `<defs>` (инструмент подготовки убирает id вне `<defs>`), отрисовка не меняется. Шумовая картинка перекодирована без потерь.
- **Стекло на строках «Saved»** (Glass в Figma): в SVG экспорт сохраняет их как полупрозрачные плашки; на фоне сайта вид совпадает с задумкой. Эталон Figma снят на прозрачном фоне, поэтому попиксельное сравнение с ним информативно, но не точно.
- **Положение бейджа Booking:** в прототипе Figma он заканчивает на 7.5 px выше, чем стоит в макете (у остальных расхождение 0.25 px). Взято положение макета (иначе зазор до точки не совпал бы с другими бейджами и первый кадр не был бы макетом); путь Booking поэтому на 7.5 px короче, чем в прототипе.
- **Инструмент сборки:** `tools/build-webflow.mjs` теперь разбирает в `motion.yaml` ключи с цифрами и отрицательные числа (нужны для `ring1`, `fromAbove`).
- **Колокольчик:** повторён пружиной Figma (масса 1, жёсткость 600, затухание 12.2); остаточный скачок конца пружины около 1.4°, как в прототипе, не виден.
