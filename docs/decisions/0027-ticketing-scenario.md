# 0027. Ticketing: сценарий, роли слоёв, цвета, шум

- **Статус:** утверждено (сценарий, роли, шум); цвета — вариант Б
- **Дата:** 2026-10-09
- **Кто утвердил:** команда Trava (в чате: согласие по пяти пунктам плана, затем «Б: подогнать под существующие» для цветов)
- **Задача бэклога:** Ticketing (иллюстрация 4)

## Контекст
Бриф: лучи слева направо с разной периодичностью, билеты слегка левитируют с разной скоростью, полосы данных переливаются слева направо как скелетон. План: [docs/plans/ticketing-start.md](../plans/ticketing-start.md).

## Решение
1. **Лучи** как в макете: левые вправо, отражённые правые влево к центру (приём `ambientFlow`, 16 лучей).
2. **Левитация** (новый приём `levitate`): задний билет ±4 px, ±0.6°, период 4.6 с; передний ±3 px, ±0.4°, период 3.4 с; синусоида (то же, что `sine.inOut` туда-обратно); билеты стартуют в разные стороны. Тень `m-shadow` стоит на месте: двигается всё остальное в билете.
3. **Переливание** (новый приём `shimmer`): одна волна белого блика (токен `illustration.placeholder.skeleton-shine`, 0.35) слева направо по 18 полосам `m-data`, волна 2.2 с, пауза 0.6 с, ширина блика 60 px; блик рисует код по форме каждой полосы.
4. **Роли слоёв:** `m-ticket` (2), `m-shadow` (2), `m-data` (18), `m-impulse` (16). Главный компонент `Illustration` лежит во внешней библиотеке и не редактируется, поэтому полосы и тень переименованы внутри двух экземпляров.
5. **Цвета** (вариант Б, как в [ADR 0025](0025-quality-control-colours-to-tokens.md)): `#003747` и `#034152` → `#013746` (`avatar.circle-end`), `#9BF4DE` → `#8CF9E5` (`accent.highlight`), цвет тени `#01212a` → `#032e39` (`shadow.frame-inner`). Правка сделана в экспорте SVG; в Figma цвета билетов не менялись (компонент из библиотеки), поэтому внешний вид чуть расходится с Figma: у данных чуть темнее и зеленее, у полоски шума на билете исчезла разница с корпусом.
6. **Шум.** Встроенный PNG зерна (230 КБ в 336 КБ файла) перекодирован без потерь в индексированный (84 КБ), пиксели идентичны (проверено сравнением всех пикселей). Уменьшение вдвое не понадобилось: файл 336 → 149 КБ без визуальной разницы.

## Что остаётся открытым
- Скорость на реальных устройствах: на билетах внутренние фильтры (тени) двигаются вместе с телом билета; замеры — в `docs/audits/qm-staging.md` после проверки.
- Цвета в Figma и в SVG расходятся (пункт 5); при желании команда может поправить библиотечный компонент.
