# 0010. Motion tokens v0

- **Статус:** утверждено (значения); формат — предложение до задачи 1.8
- **Дата:** 2026-10-05
- **Кто утвердил:** команда Trava
- **Задачи бэклога:** 1.4, 1.5

## Решение
Значения выбраны на демо-стенде `playground/motion/index.html` и записаны в `tokens/motion.tokens.json`:

| Группа | Значения |
|---|---|
| ease | enter `sine.out`, standard `power1.inOut`, exit `sine.in`, draw `power1.inOut` |
| duration | micro 0.25 с, short 0.5 с, medium 0.6 с, long 1.0 с |
| появление | сдвиг 16 px (единицы SVG), масштаб от 0.9 |
| stagger | tight 0.04 с, default 0.08 с, relaxed 0.12 с |
| запуск | порог 35 % видимости, задержка 0 с |

Формат файла — W3C Design Tokens (DTCG): кривые хранятся как cubic-bezier, имя ease для GSAP — в
`$extensions.com.gsap`. Окончательно формат и структура системы токенов утверждаются в задаче 1.8
(вместе с дизайн-токенами из Figma).

Темп Queue Manager — параметры конкретной иллюстрации, а не глобальные токены: записан в её сценарии.

## Последствия
- Анимации берут значения только из `tokens/`.
- micro (0.25) изменён командой с 0.8, выбранного на стенде по ошибке.
- 2026-10-06: добавлен `ease.flow` (равномерно, GSAP `none`) для непрерывных потоков — [ADR 0013](0013-queue-manager-continuous-flow.md).
