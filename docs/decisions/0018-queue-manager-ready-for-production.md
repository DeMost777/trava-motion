# 0018. Queue Manager принят: готов к продакшену, правила для планшета/телефона и сайта

- **Статус:** утверждено
- **Дата:** 2026-10-07
- **Кто утвердил:** команда Trava (в чате: «все работает… можем этот вариант держать как ready to production»)
- **Задачи бэклога:** 8.1, 10.2 (Queue Manager)

## Контекст
Queue Manager проверен командой на staging (`trava-website.webflow.io`): десктоп, планшет, телефон, в том числе Safari — переключение
вкладок, клик в сайдбаре, скролл, карточки подряд на малых экранах. Сайт использует два разных блока разметки: на десктопе стопка карточек
с сайдбаром (класс `is-active` у `[data-solution-state]` переключает собственный скрипт сайта), на планшете и телефоне — карточки подряд.

## Решение
1. **Версия на staging = «ready to production».** Публикация на trava.co — отдельным шагом и отдельным «утверждаю» команды; без него не выкатываем.
2. **Механизм переключения карточек сайта не меняем.** Trava Motion только читает `is-active`; настройки сайта лежат в `src/site/trava-co.js` и `.css`,
   общий runtime про разметку сайта не знает.
3. **Правила runtime для любой следующей иллюстрации:**
   - SVG подставляется только в показанную картинку, скрытая копия остаётся `<img>`;
   - у каждой копии SVG свои id; запрос файла один;
   - размеры берутся из классов сайта (runtime ширину не задаёт); десктопный размер 100 % ширины карточки — решение команды, в макете 85 %, расхождение принято;
   - alt `<img>` переносится в SVG (`role="img"` + `aria-label`); без alt иллюстрация декоративная;
   - анимация идёт, пока иллюстрация на экране ≥ 35 % и (на десктопе) её карточка активна; уход — сброс к макету.
4. **При замене картинки на SVG в Webflow alt стирается** — после замены его возвращаем (в инструкцию вставки добавлено).
5. Проверка блока «Solutions» — `qa/site-solutions.mjs` на реплике с настоящим скриптом сайта; запускать при любом изменении runtime или добавлении иллюстрации в этот блок.

## Последствия
- Для следующей иллюстрации в этом блоке нужны: SVG-ассет, атрибут `data-trava-animation` на десктопной и мобильной картинке, alt, регистрация анимации в сборке.
- Не проверено и остаётся риском: реальные устройства, кроме проверенных командой; нагрузка, когда анимаций станет несколько.
