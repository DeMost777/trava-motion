# 0036. Unused Tickets: сценарий

- **Статус:** утверждено (темп — на стенде)
- **Дата:** 2026-10-14
- **Кто утвердил:** команда Trava (в чате: «Билет ливертирует… по очереди опускаются купюры… кошелек тоже ливертирует… Лучи… Также, примени свои рекомендации выше»)
- **Задача бэклога:** Unused Tickets (иллюстрация 7 по [ADR 0012](0012-illustration-audit.md))

## Решение (вопросы плана `docs/plans/unused-tickets-start.md`, всё по рекомендации)
1. **Лучи** (9 штрихов): как в других иллюстрациях (`ambientFlow`, `m-impulse`).
2. **Билет и кошелёк** парят приёмом `levitate`: билет ±1.5 px, ±0.15°, период 4 с; кошелёк тише по тому же образцу (подбираем на стенде), в разные стороны. Тень билета стоит на месте (`m-shadow`).
3. **Купюры** (`m-bill` ×2) лежат за билетом и за кошельком (так в макете). По очереди опускаются вниз и уходят за кошелёк; кошелёк на каждом приходе слегка пружинит (масштаб 1.03, 0.3 с). Затем купюры по очереди снова выезжают из-под билета в позицию макета. Круг 6 с, первый кадр = макет.
4. **Возврат:** купюры появляются снова у билета (вариант «а» плана), не едут обратно.
5. **Вертикальная светлая полоса** (`Rectangle 3717`, «луч» между билетом и кошельком) остаётся как нарисована: вопрос о её назначении команда не уточнила, решение по рекомендации — не двигаем.
6. **Слои в Figma** (только имена, 2026-10-14): 9 штрихов → `m-impulse`; экземпляр `Illustration` → `m-card`, внутри `Shadow` → `m-shadow`; две купюры → `m-bill`; кошелёк → `m-wallet`.

## Что дальше

## Реализация (2026-10-14)
- **Цвета** (вариант Б по прецеденту Ticketing, Schedule Changes, Virtual Payments): `#003747`, `#034152` → `#013746`; `#03637C` → `#044F64`; `#33CAAF` → `#2ABDA3`; `#9BF4DE` → `#8CF9E5`; цвет тени `#01212a` → `#032e39`. Тело кошелька (корпус и полоска за клапаном) сделано `#044F64`, а не `#013746`: иначе оно сливалось с фоном страницы `#022E3A` (как карточки в Schedule Changes и Virtual Payments). Дырка застёжки остаётся `#013746`. Правки только в экспорте SVG, Figma не менялась. Билет оставлен `#013746`, как принятые билеты Ticketing.
- **Проверка экспорта:** `qa/svg-report.mjs` ругался на «inner shadow on a semi-transparent layer» у клапана и застёжки кошелька. Это ложное срабатывание: полупрозрачная текстура лежит на непрозрачной заливке того же слоя, прозрачность слоя полная, тень рисуется верно. Правило смягчено: предупреждение не выдаётся, если в слое есть непрозрачная сплошная заливка. На остальных пяти экспортах предупреждений как не было, так и нет.
- **Вес SVG:** 805 КБ (у остальных до 264 КБ) из-за двух больших шумовых картинок 2400×1800; перекодированы без потерь (1.31 МБ → 0.57 МБ в сумме). Уменьшать дальше — только с потерей качества, решение за командой (вопрос в ревью).
- **Темп** (`motion.yaml`, стенд): круг 6 с, купюры выезжают с 0.6 с (нижняя 0.9 с, верхняя через 0.5 с, 0.6 с), лежат до 3.8 с, уходят (нижняя 0.6 с, верхняя через 0.5 с, 0.9 с); кошелёк пружинит 1.03 за 0.3 с; левитация билета ±1.5 px/0.15°/4 с, кошелька ±1 px/0.1°/3.4 с.

## Правка команды после ревью (2026-10-14): путь купюр
По просьбе команды («переход купюр от билета к кошельку безшовным, gentle: вначале плавно, потом ускоряется — единственная правка») купюры больше не останавливаются на макетном месте: каждая делает один непрерывный путь из-под билета за кошелёк кривой `ease.exit` (sine.in, мягкий разгон), 2.4 с; верхняя стартует позже нижней так, что обе проходят макетное положение в один момент, с него анимация и начинается (кадр 0 = макет). Круг 4 с (был 6: пауза на месте убрана, пустой кошелёк около секунды). Остальное без изменений.
