# 0019. Client Interaction: сценарий, роли слоёв и исключение «наполнение» (небольшой bounce)

- **Статус:** утверждено (сценарий и роли); величина bounce — подбирается на стенде
- **Дата:** 2026-10-07
- **Кто утвердил:** команда Trava (в чате: ответы 1–5 на вопросы сценария)
- **Задача бэклога:** фаза 13, Client Interaction ([бриф](../../animations/client-interaction/brief.md), [сценарий](../../animations/client-interaction/storyboard.md))

## Контекст
Смысл: 5 сервисов работают как одна система (монитор в центре). Вариант A: фоновые штрихи + поток от сервисов к монитору, непрерывно.
В макете нет штрихов на пунктирных соединениях, а принципы ([§1](../../motion/principles.md)) запрещают bounce в обычном движении.

## Решение
1. **Штрихи основного потока создаёт код** как копии существующего `m-impulse` (тот же градиент). Они видны только пока идёт анимация;
   дизайн в Figma не меняется, в статике и при reduced motion — ровно макет.
2. **Реакция монитора:** zoom-in глифа `m-core` с небольшим bounce (overshoot), без вращения; карточка `m-hub` неподвижна. Эффект: «иконка наполнилась».
   **Это исключение из принципа §1 «без bounce»**, только для этого эффекта (по образцу [ADR 0007](0007-meaningful-loop-exception.md)); остальное движение — без bounce.
   Величина overshoot — «небольшая»: подбираем на стенде (варианты показываем, команда выбирает), затем фиксируем токеном.
3. **Реакция сервисов:** лёгкая пульсация `m-node` 1 → 1.08 → 1 (без bounce) в момент выхода штриха.
4. **Порядок и темп:** по часовой стрелке от Email: Email → SMS → Web → сеть → HTTP; шаг 0.7 с, раунд 3.5 с, дальше без паузы;
   скорость штриха как в Queue Manager (одна система карточек).
5. **Фон:** 9 штрихов `m-impulse` идут к центру (направление задано градиентом в макете), медленнее потока и не синхронно, непрерывно.
6. **Роли слоёв** (переименованы в рабочей копии `761:8858`, только имена, геометрия не менялась — проверено):
   `m-connection`×5 (пунктиры), `m-node`×5 (сервисы), `m-hub` (карточка монитора), `m-core` (глиф монитора), `m-impulse`×9 (фон).
   В словарь добавлены `m-node` и `m-core`; `m-connection` (уже был) теперь используется и в Client interaction.

## Последствия
- Нужен новый приём `routeFlow` (штрих по маршруту с поворотом, подпись по геометрии `m-connection`): добавляем в список primitives (5.1).
- Новый spec-формат не требуется (допущения 3.2 не нужны).
- Следующие шаги: экспорт SVG, подготовка по ADR 0014, `motion.yaml`, стенд с видео, ревью, затем вставка на staging по ADR 0018.
