# 0020. Client Interaction: значения со стенда и токен `shadow.node`

- **Статус:** утверждено
- **Дата:** 2026-10-07
- **Кто утвердил:** команда Trava (в чате: «B, средний, добавляй токен shadow.node»)
- **Задачи бэклога:** фаза 13 (Client Interaction); дополняет [ADR 0019](0019-client-interaction-scenario.md)

## Решение
1. **Порядок B:** штрихи приходят в монитор с шагом 0.7 с, монитор бьётся ровным ритмом (`alignArrival: 1`). Приходы идут по часовой стрелке от Email;
   выходы из сервисов при этом не строго по часовой (HTTP раньше сети) — следствие разной длины маршрутов.
2. **Отскок монитора — средний:** `coreOvershoot: 0.3` (глиф доходит до 1.26 и садится на 1.2). Остальные значения — как в ADR 0019 и `motion.yaml`.
3. **Токен `shadow.node`** = `#181818`, α 0.25 (тень под иконками-сервисами, как в Figma) добавлен в `tokens/illustration.tokens.json`.
   Тень аватаров Queue Manager (`shadow.avatar`, `#020c15`, α 0.24) не менялась. Дизайн в Figma не правился.

## Последствия
- Проверка пакета (`prepare-svg` пакетный режим) проходит, сборка для сайта (`tools/build-webflow.mjs`) снова работает на всех пакетах.
- Переменная `shadow/node` в Figma (коллекция Illustration) не создавалась: токен пока только в репозитории.
- Размер сборки 42 КБ при пределе ≈ 50 КБ — вопрос Q25 (до третьей иллюстрации).
