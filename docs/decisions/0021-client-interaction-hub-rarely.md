# 0021. Client Interaction: монитор пульсирует редко, раз за раунд

- **Статус:** утверждено
- **Дата:** 2026-10-08
- **Кто утвердил:** команда Trava (в чате, после просмотра итогового видео: «слишком часто пульсирует… совсем периодически, примерно как gear icon»)
- **Задача бэклога:** фаза 13 (Client Interaction); меняет пункт 5 [ADR 0020](0020-client-interaction-values.md) и реакцию монитора из [ADR 0019](0019-client-interaction-scenario.md)

## Решение
Глиф монитора (`m-core`) «наполняется» **один раз за раунд** (раз в 3.5 с), когда приходит штрих первого сервиса раунда (Email), и длится 1.3 с как gear в Queue Manager
(0.4 с zoom-in с отскоком 0.3 + 0.9 с возврат). Раньше он пульсировал на каждом из пяти приходов (каждые 0.7 с). Остальное не менялось.
Какой сервис запускает пульсацию — параметр `coreArrival` (0 = первый).

## Последствия
- Отскок монитора остаётся единственным исключением из принципа §1 (ADR 0019); варианты размера отскока (видео `client-interaction-bounce.mp4`) больше не нужны, файл удалён.
- Первая пульсация монитора — на 2.3 с после старта, дальше каждые 3.5 с.
