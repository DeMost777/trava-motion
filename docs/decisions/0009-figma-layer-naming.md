# 0009. Именование анимируемых слоёв в Figma

- **Статус:** утверждено
- **Дата:** 2026-10-05
- **Кто утвердил:** команда Trava
- **Задача бэклога:** 1.6

## Решение
- Имена получают только анимируемые слои и слои-ориентиры: `m-<роль>`, роль на английском, kebab-case.
- Одинаковая роль — одинаковое имя (вариант A); порядок и направление движения вычисляются по геометрии.
- Общий словарь ролей в `docs/figma-layer-naming.md`.
- Переименование выполняет Claude через Figma MCP в рабочем файле или ветке, с проверкой «до/после».

## Последствия
Queue Manager: 24 × `m-impulse`, `m-gear`, `m-hub` (выполнено и проверено).
Подготовка SVG (фаза 2) опирается на эти имена.
