- **План и вопросы:** `docs/plans/quality-control-start.md`

## Решение
1. **Лучи.** 16 штрихов `m-impulse` внутри `blinds` идут по своим линиям слева направо, у каждого своя пауза (`ambientFlow`, скорость как в Client Interaction). Вертикальный штрих и три безымянных у карточки (`bg image`) неподвижны; код берёт только горизонтальные штрихи.
2. **Иконки** `m-node` ×5 пульсируют по очереди, по часовой от верхней левой: статистика → почта → пользователи → XML → пользователь с письмом; шаг 0.7 с, пульс 1 → 1.08 → 1 (`pulse`, значения как в Client Interaction).
3. **Полоса.** `m-progress` растёт слева направо от 0 до места из макета (51 из 123 px), `m-knob` едет за ней. Макет = конечное состояние; покой, reduced motion и уход с экрана показывают макет.
4. **Число 12.380 не считается** (Figma экспортирует текст контурами, цифр 0–9 нет). Вместо счёта — **эффект ожидания: заглушка-скелет** на месте числа (мягкая плашка с бегущим бликом), когда полоса приходит, плашка сменяется числом `m-number`. Формат «12.380» как в макете.
5. **Лупа** `m-lens`: zoom-in с отскоком (`pulse` с overshoot, как центральная иконка Client Interaction), в момент появления числа, раз за раунд.
6. **Раунд 7 с** (предложение, подбираем на стенде): 0–2.5 с полоса растёт, в 2.5 с число и лупа, 2.5–5.5 с пауза, 5.5–6.3 с число гаснет и полоса возвращается к 0, до 7 с пауза.
7. **Новые токены** `illustration.placeholder.skeleton` (белый, α 0.18) и `illustration.placeholder.skeleton-shine` (белый, α 0.35): плашку рисует код, в макете её нет, в покое не видно. Значения уточняем на стенде.
8. **Новые роли** в словаре слоёв: `m-progress`, `m-knob`, `m-number`, `m-lens`; `m-node` теперь и в Quality Control. Слои в Figma названы (761:9380–9384 → `m-node`, 761:9360 → `m-progress`, 761:9361 → `m-knob`, 761:9372 → `m-number`, 761:9373 → `m-lens`), геометрия не менялась.

## Исключение из принципов
Плашка-скелет — элемент, которого нет в макете. Он существует только пока анимация идёт и исчезает вместе с ней (принцип 9: без анимации иллюстрация полностью читаема). Так же устроены штрихи `routeFlow` в Client Interaction.
