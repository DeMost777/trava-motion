# 0006. Motion principles

- **Статус:** утверждено
- **Дата:** 2026-10-02
- **Кто утвердил:** команда Trava
- **Задача бэклога:** 1.3

## Решение
Утверждён `motion/principles.md` (по интервью). Коротко: спокойное и точное движение без bounce;
последовательность 2–3 с с перекрытием шагов; один мягкий акцент; появление через fade + небольшой
сдвиг/масштаб; один запуск при появлении секции, а для продуктовых карточек — при каждой активации;
при прерывании — мгновенно в финальный кадр; после — полная статика; без hover в V1;
mobile — та же анимация с упрощением по необходимости; reduced motion — сразу статика.

Уточнение при утверждении: карточки сменяются по мере скролла секции и по клику в сайдбаре.

Числовые значения — в системе токенов (задачи 1.4–1.5, 1.7–1.9).
