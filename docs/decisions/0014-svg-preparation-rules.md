# 0014. Правила подготовки SVG из Figma

- **Статус:** утверждено
- **Дата:** 2026-10-07
- **Кто утвердил:** команда Trava (в чате)
- **Задача бэклога:** 2.3

## Контекст
Отчёты 2.1 и 2.2: экспорт Figma пригоден для анимации, но тень на фрейме Queue Manager экспортируется неверно
(в браузере затемняет всё, анимация ~7 кадров/с); id слоёв конфликтуют между иллюстрациями; 14 импульсов
повёрнуты или отражены трансформами.

## Варианты
См. [docs/svg-prep-rules.md](../svg-prep-rules.md), раздел 4: по каждому решению 2–3 варианта.

## Решение
Утверждены правила [docs/svg-prep-rules.md](../svg-prep-rules.md):
1. Подготовка не меняет ничего видимого; меняет только техническое (лишние id, роли, размеры, метка, aria).
2. **Тень фрейма (А2):** в Figma (рабочая копия) тень фрейма заменена кольцом-градиентом `#032E39` на круге свечения.
   Рендер Figma до/после — средняя разница 0.94 из 255; угловые аватары стали чуть светлее (утверждено).
3. **Правило дизайна:** в иллюстрациях нет внутренних теней на фреймах и на полупрозрачных слоях.
   `qa/svg-report.mjs` выдаёт предупреждение.
4. **Роли:** атрибут `data-m="…"` вместо id.
5. **Трансформы:** не трогаем, направление считает runtime.
6. **Эталон:** снимок фрейма из Figma без фона (`contentsOnly`), PNG 1x без потерь.

## Последствия
- Нужен новый экспорт Queue Manager после правки (старый содержит тень фрейма).
- Инструмент 2.4 применяет правила и проверяет результат против эталона.
- Правка А2 сделана в рабочей копии; перенос в оригинал `418:30757` — отдельное решение (по Q22 не переносим).
