## Решение
Утверждён `animations/queue-manager/storyboard.md`: вход = первая волна; «бегущий импульс» по эстафете,
синхронно и симметрично к центру; прибытие в карточку; gear — поворот 360° + zoom без отскока;
пауза (кадр = макет); бесконечный цикл, пока карточка активна и видна (исключение по ADR 0007).
