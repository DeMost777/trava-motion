# 0017. Доставка анимаций на сайт Webflow

- **Статус:** утверждено (ответы команды 2026-10-07); проверено на staging (десктоп, планшет, телефон, Safari) — см. [0018](0018-queue-manager-ready-for-production.md)
- **Дата:** 2026-10-07
- **Кто утвердил:** команда Trava (в чате: «GSAP пока нет», «ассеты Webflow», «подготовь пошаговую инструкцию»)
- **Задачи бэклога:** 4.1, 4.2, 10.1 (короткий путь для Queue Manager, [план](../plans/qm-to-site.md))

## Контекст
На сайте GSAP не подключён. Файлы — через ассеты Webflow. Код в Webflow вставляет команда по инструкции.
Подготовленный SVG весит 154 КБ — больше, чем, по нашим данным, помещается в элемент Embed (около 50 000 символов),
поэтому встроить SVG в разметку нельзя.

## Варианты
1. SVG встроить в Embed — не помещается.
2. **SVG в ассетах как обычная картинка `<img>`, скрипт превращает её во встроенный SVG** ✔ — статичная картинка
   работает и без скрипта (анимация — enhancement).
3. Внешний хостинг файлов — отложено (команда выбрала ассеты Webflow).

## Решение
- `queue-manager.svg` → Assets Webflow, стоит в карточке как обычное изображение с атрибутом
  `data-trava-animation="queue-manager"`.
- GSAP 3.15.0 — с CDN jsDelivr (версия закреплена).
- `trava-motion.js` (runtime + primitives + анимации, 16 КБ) — текстом в Custom code страницы, перед `</body>`.
  Файл собирает `tools/build-webflow.mjs`; ассеты Webflow, по нашим данным, не принимают `.js`.
- Runtime: при видимости ≥ 35 % (токен) загружает SVG, встраивает и запускает анимацию; при уходе — сброс к макету;
  без GSAP, при reduced motion, ошибке загрузки или скрипта — остаётся статичная картинка.

## Последствия и риски (проверить на staging)
- **CORS:** скрипт читает SVG с сервера ассетов Webflow. Если сервер не разрешит — анимации не будет, картинка останется
  статичной (сайт не ломается). Тогда — план Б (внешний хостинг SVG или сжатие SVG, чтобы влез в Embed).
- **Одинаковые id:** если одна и та же иллюстрация окажется на странице дважды (например, отдельная мобильная вёрстка) и
  первая скрыта, градиенты второй ломаются — проверено в браузере. Сейчас такого случая нет; при появлении — префикс id.
- Обновление: пересобрать `tools/build-webflow.mjs`, заменить ассет и код по инструкции.
