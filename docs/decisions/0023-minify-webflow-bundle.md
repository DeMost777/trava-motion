# 0023. Сборка для Webflow минифицируется (Q25, вариант А)

- **Статус:** утверждено
- **Дата:** 2026-10-08
- **Кто утвердил:** команда Trava (в чате: «Утверждаю, делай А»)
- **Вопрос:** Q25 в `docs/open-questions.md`

## Контекст
Поле Custom code страницы в Webflow ограничено ≈ 50 000 символов (данные из ADR 0017). Код с двумя анимациями занимал 42 519 символов,
около 8,6 КБ из них — комментарии. Третья иллюстрация упёрлась бы в предел.

## Решение
1. `tools/build-webflow.mjs` дополнительно собирает `exports/webflow/trava-motion.min.js` (terser: compress + mangle; комментарий-шапка `/*!` остаётся).
2. `webflow-custom-code.html` (то, что вставляют в Webflow) содержит сжатый код. Читаемый `trava-motion.js` остаётся для разработки и тестов.
3. Новая зависимость для разработки — `terser` 5.51.2 (`package.json`, `npm install`). В рантайме зависимостей по-прежнему нет.
4. Проверки гоняются на обоих вариантах: `TM_BUNDLE=min node qa/site-solutions.mjs` и `qa/animation-check.mjs` проверяют сжатую сборку.
5. Варианты Б (внешний хостинг файла) и В (профили «страница → анимации») не делаем сейчас; вернёмся, если главная снова упрётся в предел.

## Результат
| | до | после |
|---|---|---|
| `webflow-custom-code.html` | 42 519 | 20 468 символов |
| `trava-motion.js` → `.min.js` | 42 042 | 19 991 B |

`qa/site-solutions.mjs`: 26 проверок ok и на читаемой, и на сжатой сборке. `qa/animation-check.mjs` (Client Interaction, сжатая): все ok.
Проверка «bars are moving» на Queue Manager падает и на несжатой сборке — она написана под Client Interaction (ищет бары с `matrix`), к минификации не относится.

## Последствия
- Запас в поле Custom code ≈ 29 500 символов.
- В Webflow лежит нечитаемый код; источник правды — репозиторий. Править код в Webflow нельзя (как и раньше).
- Footer главной на staging заменён на сжатую версию (20 468 символов) 2026-10-08, публикация только на webflow.io (task `c1982f2d-ef0e-4447-9b97-7ec8837b51c3`); trava.co не затронут. Проверено командой на staging («Проверил на staging, всё работает»): обе анимации и консоль в порядке.
