# 0002. Языки: документация, skills, спецификации

- **Статус:** утверждено
- **Дата:** 2026-10-02
- **Кто утвердил:** команда Trava
- **Задача бэклога:** 0.5

## Контекст
Команда общается и пишет брифы на русском. Модели надёжнее работают с инструкциями на английском,
а описания skills участвуют в автоматическом выборе skill.

## Решение
| Что | Язык |
|---|---|
| Документация для людей (README, docs/, BACKLOG, ADR) | русский |
| Бриф анимации от человека (`brief.md`) | русский |
| Skills (`.claude/skills/`), subagents | английский |
| Motion Specification (`motion.yaml`) и всё, что получает агент-разработчик анимации | английский |
| Код и комментарии в коде | английский |

Orchestrator переводит бриф на английский при создании spec. Исходный бриф хранится рядом,
а человеку при утверждении показывается краткий пересказ spec на русском.

## Последствия
- CLAUDE.md остаётся на русском (правила для работы с командой).
- В шаблон пакета анимации добавлен `brief.md`.
