# Pipeline

Черновик. Этапы утверждаются по мере прохождения фаз (см. BACKLOG.md).
Для каждого этапа фиксируем вход, выход и **как мы проверяем, что этап сработал**.

| # | Этап | Вход | Выход | Как проверяем | Фаза |
|---|---|---|---|---|---|
| 1 | Экспорт из Figma | фрейм иллюстрации | SVG + PNG-референс | SVG в браузере выглядит как PNG | 2 |
| 2 | Подготовка SVG | сырой SVG | SVG с именованными элементами, адаптивный | внешний вид не изменился (сравнение с PNG), нужные элементы адресуемы | 2 |
| 3 | Motion Spec | бриф словами | структурированный spec | человек читает spec и узнаёт свой бриф | 3 |
| 4 | Валидация spec | spec + SVG | список ошибок | ловит заведомо неверные spec (тестовые примеры) | 3 |
| 5 | Реализация | spec + primitives | анимация | играет по spec, финальный кадр = дизайн | 5–6 |
| 6 | Preview | анимация | страница с контролами | человек смотрит на 3 размерах и в reduced motion | 7 |
| 7 | QA | анимация | отчёт | ловит заведомо сломанные анимации | 9 |
| 8 | Webflow | анимация | embed + runtime | работает на staging-странице Webflow | 10 |

Для каждого этапа сначала проходим путь **вручную**, затем автоматизируем и только после этого
записываем как skill для AI.
