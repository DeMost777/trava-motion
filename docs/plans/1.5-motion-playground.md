# План: демо-стенд motion-токенов (задача 1.5)

**Статус:** план утверждён (2026-10-05), стенд сделан: `playground/motion/index.html`. Ждём выбор значений.

## Цель
Выбрать **глазами** числовые значения motion-токенов (задача 1.4) и темп Queue Manager:
одни и те же объекты двигаются рядом с разными параметрами, вы выбираете вариант.
Стенд — инструмент для решения, а не продакшн-код: после выбора значений он остаётся как справочный.

## Где и как
- Файл: `playground/motion/index.html` — одна страница, без сборки и без npm.
- GSAP подключается со CDN с зафиксированной версией (`gsap@3.15`). Стек проекта решается в фазе 4,
  стенд на него не влияет.
- Открыть: локально двойным кликом по файлу в браузере (Claude Code у нас локальный).
- Визуал в стиле карточек Trava: тёмный teal-фон панели, бирюзовые акценты из Figma
  (`Primary/700 #075a70` и цвета импульсов). Дизайн-токенов пока нет — цвета временные.

## Разделы стенда

| # | Раздел | Что показываем | Что выбираете |
|---|---|---|---|
| 1 | **Easing** | один и тот же объект появляется / перемещается с 5–6 кривыми рядом (power1–3.out, expo.out, sine.inOut, power2.inOut) | кривые для ролей `enter`, `standard` (перемещение), `exit`, `draw` |
| 2 | **Длительности** | одна кривая, длительности 0.2 / 0.35 / 0.5 / 0.6 / 0.8 / 1.0 с | значения `micro`, `short`, `medium`, `long` |
| 3 | **Появление** | fade + сдвиг 4 / 8 / 12 / 16 px и fade + масштаб от 0.85 / 0.9 / 0.95 | дистанцию сдвига и стартовый масштаб |
| 4 | **Stagger** | группа из 8 узлов с задержками 0.04 / 0.06 / 0.1 / 0.16 с | `tight`, `default`, `relaxed` |
| 5 | **Темп Queue Manager** | упрощённая схема 5×5 (не настоящий SVG — он будет в фазе 2): волна импульсов к центру, поворот + zoom gear, пауза. Слайдеры: время отрезка, сдвиг волн по глубине, длительность и масштаб zoom gear (1.1 / 1.2 / 1.3), пауза | темп волны, параметры gear, длину паузы |
| 6 | **Запуск при скролле** | блок ниже экрана; порог 25 / 35 / 50 % видимости и задержка 0 / 0.15 / 0.3 с | порог и задержку (вопрос Q19) |

**Управление в каждом разделе:** Replay, скорость 1× / 0.5×, подписи вариантов (A, B, C…).
Внизу страницы — панель «Выбранные значения»: показывает текущий выбор, его можно скопировать и прислать мне.

## Что не входит
Настоящая иллюстрация из Figma, runtime, дизайн-токены (цвета), Webflow. Только движение.

## Выбор команды (2026-10-05), до записи в токены
```json
{
  "ease": { "enter": "sine.out", "standard": "power1.inOut", "exit": "sine.in", "draw": "power1.inOut" },
  "duration": { "micro": 0.8, "short": 0.5, "medium": 0.6, "long": 1 },
  "distance_px": 16, "scale_from": 0.9,
  "stagger": { "tight": 0.04, "default": 0.08, "relaxed": 0.12 },
  "queueManager": { "segment": 0.5, "offset": 0.2, "gear": 1.5, "zoom": 1.2, "pause": 1.2, "waveSeconds": 1.1, "cycleSeconds": 3.8 },
  "trigger": { "threshold": null, "delay": 0 }
}
```
Открытые вопросы перед записью: `micro` (0.8) больше `short` (0.5); порог запуска не выбран.

## Правка схемы Queue Manager (2026-10-05)
- Геометрия взята из `absoluteBoundingBox` слоёв Figma. Раньше использовались координаты точки
  поворота: у повёрнутых импульсов (правая половина и вертикальные) они смещены на 18–20 px.
- Пунктир — по координатам линий из Figma (в макете ряды 1–2 на 1–2 px ниже центров аватаров).
- Градиент импульсов как в Figma: `rgba(16,176,148,0)` (хвост) → `rgba(17,176,149,1)` (голова к центру),
  в том числе у вертикальных.
- Каждый импульс движется внутри маски = своя линия, обрезанная по краю аватара и карточки: уходит в узел,
  не рисуясь поверх. Проверка по всему циклу с шагом 0.02 с: пересечений с аватарами и карточкой — 0 px.
