## Блокер: передача файла в репозиторий
Сетевая политика среды запрещает хост **www.figma.com**: ссылки на экспорт из Figma не скачиваются
(ответ прокси 403). Варианты:
- **A (рекомендую).** Разрешить `www.figma.com` в настройках среды (Network access → Custom → Allowed domains).
  Экспорт станет полностью автоматическим и повторяемым — это пригодится для всех 8 иллюстраций.
- **B.** Экспортировать вручную: в Figma выделить фрейм → Export → SVG с галочкой «Include "id" attribute»
  и PNG 2x, прислать файлы. Работает сразу, но каждый раз руками.
- **C.** Передать SVG через ответ Figma-инструмента по частям. Не рекомендую: 157 КБ, высокий риск
  испортить файл при переносе.

## Проверка варианта C (2026-10-06)
Экспорт через `use_figma` работает (156 842 символа, FNV-1a `1423f155`, id `m-impulse` … `m-impulse_24` —
Figma сама делает id уникальными суффиксами `_2…_24`), но **ответ инструмента обрезается до 20 КБ**, а на диск
сохраняются только картинки. Перенести 157 КБ можно лишь кусками с ручной перепечаткой — ненадёжно. Вариант C отпал.
Остаются A (разрешить `www.figma.com`) и B (ручной экспорт). При локальном запуске Claude Code (ADR 0003)
этой проблемы нет: ссылки Figma скачиваются напрямую.
