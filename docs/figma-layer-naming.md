# Именование слоёв в Figma

**Статус:** ✅ утверждено ([ADR 0009](decisions/0009-figma-layer-naming.md)). Queue Manager переименован 2026-10-05.

## Зачем
Анимация обращается к элементам иллюстрации по имени. При экспорте в SVG Figma превращает имя слоя
в `id` (включается опцией «Include id attribute»). Сейчас слои называются автоматически (`Vector 137`,
`Rectangle 2180`): такие имена ломаются при любой правке макета и ничего не говорят о роли элемента.

## Правила (для всех иллюстраций)
1. **Имя получают только слои, которые анимируются или нужны анимации как ориентир**
   (например, границы карточки, у которой гаснут импульсы). Остальные слои не трогаем.
2. **Формат:** `m-<роль>` — префикс `m-` и роль на английском, строчными буквами, через дефис:
   `m-impulse`, `m-gear`, `m-hub`. Префикс отличает «анимационные» слои от прочих и надёжно находится в SVG.
3. **Имя описывает роль, а не внешний вид или место:** `m-impulse`, а не `m-green-line` или `m-line-left`.
4. **Одинаковая роль — одинаковое имя.** 24 импульса называются одинаково, `m-impulse`
   (при экспорте Figma добавит `_2`, `_3`…, подготовка SVG это учитывает).
5. **Что движется вместе — в одну группу**, имя даётся группе (например, маркер с подписью).
6. **Не делать outline stroke** для линий, которые будут «рисоваться», и не сливать анимируемые
   элементы в один vector.
7. **Словарь ролей общий для всех иллюстраций** (ниже). Новую роль сначала добавляем в словарь.

## Словарь ролей (растёт с каждой иллюстрацией)
| Роль | Что это | Где встречается |
|---|---|---|
| `m-impulse` | короткая светящаяся полоса, бегущая по линии | Queue Manager, Client interaction |
| `m-gear` | иконка механизма, которая вращается | Queue Manager |
| `m-hub` | центральная карточка, куда сходятся потоки | Queue Manager |
| `m-passenger` | иконка пассажира | Queue Manager (пока не анимируется) |

## Открытый выбор: как различать одинаковые элементы
Анимации Queue Manager нужно знать, где какой импульс и в каком порядке он стартует.

- **A. Только роль, порядок по геометрии** ✔ *выбрано*: все 24 слоя называются `m-impulse`.
  Код сам вычисляет по координатам, на какой линии лежит импульс, куда ему бежать (к центру)
  и его «глубину» (сколько отрезков до карточки). Переименовать нужно 26 слоёв, макет можно двигать
  и перерисовывать без переименований.
- **B. Роль + место в сетке**: `m-impulse-r1-c1c2` (ряд 1, от колонки 1 к 2). Всё явно видно в Figma,
  но 24 уникальных имени, их легко перепутать, и при изменении сетки нужно переименовывать.
