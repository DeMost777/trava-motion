## 2. Повторяющиеся паттерны движения

| Паттерн | Где встречается | Кандидат в primitive |
|---|---|---|
| **Импульсы / штрихи по линиям** (зелёные градиентные полосы) | QM (по сети к центру), Ticketing, QC (едут вправо), Schedule, Client interaction, VP, Unused | `impulseFlow` — движение полосы вдоль своей линии с обрезкой по узлам (уже проверено на стенде QM) |
| **Появление узлов/иконок по очереди** | QC (5 спутников), Client interaction (5 каналов), FO (точки графика) | `staggerReveal` (fade + масштаб от 0.9, stagger из токенов) |
| **Акцент центрального элемента** | QM (gear), Client interaction (монитор), QC (лупа) | `hubAccent` (поворот/zoom/«активация» без отскока) |
| **Отрисовка соединений** | Client interaction (пунктир к каналам), VP (линия карта → Activity), Schedule (подвесы) | `drawLine` (в т.ч. пунктир) |
| **Появление карточки/панели** | QC (карточка), Schedule (табло), VP (карты, Activity), FO (панель уведомлений), Ticketing (билеты) | `cardEnter` (fade + сдвиг/масштаб) |
| **Список / уведомления по очереди** | Schedule (строки табло), FO (Saved 80/120/160€), QC (столбики) | `listStagger` / `notificationStack` |
| **График / столбики** | FO (линия цены), QC (столбики), VP (мини-столбики) | `chartDraw`, `barsGrow` |
| **Перенос по траектории** | Unused (купюры билет → кошелёк), VP (линия к Activity) | `travelAlongPath` (приземление в позицию макета) |
| **Смена числа/статуса** | QC (12.380), VP (3.44%), Schedule (Canceled/Delay) | `counter`, `statusHighlight` — **только если текст живой** (см. риски) |

Вывод: ~8–9 primitives покрывают все 8 иллюстраций. Импульсы — общий «язык» почти всех карточек;
первыми стоит сделать `impulseFlow`, `staggerReveal`, `hubAccent`, `drawLine`, `cardEnter`.

## 3. Расхождения с утверждёнными принципами (в черновых keyframes Figma)
- Spring / overshoot (`cubic-bezier(0.7,-0.4,0.4,1.4)`, spring-кривые) — в Ticketing, QC, FO, gear QM. Принцип §1: без отскоков.
- Бесконечные циклы во всех 4 прототипах. По ADR 0007 цикл допустим только как утверждённое смысловое исключение.
- Это черновики дизайнера: при сценарии каждой иллюстрации решаем, что берём по смыслу, а движение делаем по принципам и токенам.
