## Как устроен сайт (прочитано через Webflow MCP, только чтение)
- Десктоп (шире 991 px): `.solutions-scroll-track` показан, `.solution-responsive` скрыт. Скрипт во встроенном блоке страницы переключает
  класс `is-active` у `[data-solution-state]` и `[data-solution-nav]` (скролл по `[data-solution-step]` и клик). Неактивные состояния лежат
  стопкой: `opacity:0; visibility:hidden` (пересечение с экраном для браузера остаётся).
- Планшет и телефон (≤ 991 px): `.solutions-scroll-track` скрыт, карточки идут подряд в `.solution-responsive`, у каждой своя картинка
  `solution-responsive-image` (размеры 100 %/макс. 400, 80 %/340, 90 %/300 по брейкпоинтам). Родителя `data-solution-state` у них нет.

- Переключение карточек сайтом с Trava Motion и без него идентично; высота карточки та же (скрипт сайта читает её для линии переключения).
