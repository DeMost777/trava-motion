## 3. Выводы
1. **Иллюстрации используют свою «палитру иллюстраций»**: бирюзовые градиенты (`#2abda3`/`#8cf9e5`,
   `#25c0a4`/`#146f5e`, `#10b094`), тёмные teal-фоны, светлая рамка карточки, тени. Её нет в переменных:
   из 25 уникальных цветов POC к переменным привязаны только 2.
2. Многие значения **близки, но не равны** переменным сайта (Δ 6–20). Привязать их «к ближайшей» нельзя
   без изменения внешнего вида — это противоречит принципу «Figma — source of truth, дизайн не меняем».
3. **Повторы между иллюстрациями есть** (градиент `#2abda3 → #8cf9e5`, `Primary/700`, `Primary/950`, белый),
   то есть палитра иллюстраций действительно общая — её стоит закрепить токенами.
4. Тени и текст в иллюстрациях не стилизованы.

## 4. Варианты для 1.8 (решение команды)
- **A. Коллекция переменных «Illustration» в Figma** *(рекомендация)*: дизайнер (или Claude с разрешения) создаёт
  переменные ровно с текущими значениями (вид не меняется) и привязывает к ним слои. Figma остаётся source of truth,
  токены в DTCG выгружаются из Figma. Новые иллюстрации обязаны брать цвета из коллекции.
- **B. Только в репозитории**: фиксируем палитру иллюстраций в `tokens/` по фактическим значениям, в Figma ничего
  не меняем. Быстро, но Figma и токены могут разойтись.
- **C. Привязать к существующим переменным сайта**: внешний вид изменится (Δ до ~20) — нужно решение дизайнера.
