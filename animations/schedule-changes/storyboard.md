# Schedule Changes — сценарий (✋ утверждён 2026-10-09, [ADR 0030](../../docs/decisions/0030-schedule-changes-scenario.md))

**Смысл:** изменение расписания рейсов. Движение: [бриф](brief.md). Принципы: `motion/principles.md` (кадр 0 = дизайн, reduced motion = макет).

## Что есть в макете (Figma `761:8758`, 480×394)
- **6 лучей** `m-impulse` на коротких пунктирных линиях (левые смотрят вправо, правые отражены и смотрят влево).
- **5 строк** `m-row` табло «Departures»: Berlin, Toronto, Madrid, Paris, Sydney. В строке подложка и четыре текста (город, рейс, гейт, статус).
- Не двигаются: заголовок, шапка столбцов, глобус, карточка с тенью, вертикальные штрихи над карточкой.
- Цвета подогнаны под существующие токены, тёмные строки (Toronto, Paris) стали одного цвета с карточкой ([ADR 0030](../../docs/decisions/0030-schedule-changes-scenario.md)).

## Сцены (непрерывно, пока карточка видна и активна)
1. **Лучи.** Каждый луч идёт по своей линии, у каждой своя пауза (как фон в Client Interaction).
2. **Строки как домино.** Сверху вниз: Berlin → Toronto → Madrid → Paris → Sydney, шаг 0.4 с. Строка целиком (подложка и тексты) вокруг своего центра растёт до 1.06 за 0.3 с и плавно возвращается за 0.45 с; соседние строки чуть перекрываются во времени. Последняя заканчивает на 2.35 с, пауза, круг 4 с и всё сначала.

Первый кадр = макет (все строки в исходном размере).

## Что подобрать на стенде
Величину увеличения (1.06), шаг и длительности, паузу между кругами.
