# Quality Control — сценарий (✋ утверждён 2026-10-08, [ADR 0024](../../docs/decisions/0024-quality-control-scenario.md))

**Смысл:** автоматическая проверка бронирований. Движение: [бриф](brief.md). Принципы: `motion/principles.md` (кадр 0 = дизайн, reduced motion = макет).

## Что есть в макете (Figma `761:9334`, 480×480)
- **16 лучей** `m-impulse` на коротких пунктирных линиях (4 ряда × 4 колонки), все смотрят вправо; ещё один вертикальный штрих под карточкой и три безымянных у карточки.
- **5 иконок** `m-node` вокруг карточки: статистика (верх слева), почта (верх справа), пользователи (справа), XML (внизу), пользователь с письмом (слева).
- **Карточка** «Daily Reservations»: число `m-number` «12.380», столбики, лупа `m-lens`, полоса загрузки: заливка `m-progress` (51 из 123 px) и ползунок `m-knob`.
- Цвета подогнаны под существующие токены ([ADR 0025](../../docs/decisions/0025-quality-control-colours-to-tokens.md)).

## Сцены (непрерывно, пока карточка видна и активна)
1. **Лучи.** 16 штрихов идут слева направо по своим линиям, у каждой своя пауза (как фон в Client Interaction). Вертикальный штрих и три безымянных остаются как нарисованы.
2. **Иконки по очереди.** По часовой от верхней левой: статистика → почта → пользователи → XML → пользователь с письмом, шаг 0.7 с, круг 3.5 с. Пульс 1 → 1.08 → 1.
3. **Загрузка, раунд 7 с.** 0–2.5 с заливка растёт от 0 до места из макета, ползунок едет за ней; на месте числа мягкая плашка с бегущим бликом.
   В 2.5 с полоса пришла: плашка уступает числу, число чуть поднимается (2 px) и проявляется (0.4 с). 2.5–5.5 с пауза: макет в готовом виде.
   5.5–5.9 с число гаснет, плашка возвращается; 5.5–6.3 с заливка мягко идёт назад к 0; до 7 с пауза и новый раунд.
4. **Лупа.** В 2.5 с, когда появилось число, лупа делает zoom-in с небольшим отскоком (1 → 1.2, отскок 0.3) и возвращается за 1.3 с; раз за раунд.

Анимация стартует с 3-й секунды раунда: первый кадр = макет, дальше полоса уходит назад и заполняется заново.
Плашка-скелет рисуется кодом и есть только пока анимация идёт (исключение в ADR 0024). Число не считается: в SVG это контуры.

## Что подобрать на стенде
Длительность заполнения (2.5 с), паузы, сила бликов плашки (токены `placeholder.*`), величина отскока лупы.
